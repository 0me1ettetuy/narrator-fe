The product feature catalogue is intentionally maintained once, in the backend
repository, because every feature combines API/worker/storage behavior with a
frontend experience.

Read the [cross-repository feature catalogue](../../../narrator-general-api/docs/features/README.md)
for current capabilities, UI flows, technical behavior, contributing commits,
and explicit implementation boundaries.
